**Tower Defend - C Project :**



University project (L2 Computer Science - University of Poitiers) developed in C with the SDL library.





**Game objective :**



Automated game where a horde of attacking units advances along a path to destroy the King's tower.



Two factions : The "King" (defensive towers) faces the "Horde" (dragons, archers, knights, gargoyles).





Procedural generation : The attack path and the spawning of units are generated randomly.





Algorithmics : Optimized and automatic placement of defense towers.





**Technical concepts explored :**



Data structures : Modeling of players via singly linked lists and of the board via a 2D array.





Memory management : Intensive use of pointers and dynamic allocations (malloc).





Data persistence : Saving and loading of games via binary (.tdb) and sequential (.tds) files.





Graphical interface : 2D rendering engine managed with the SDL.





**Installation and Launch**



This project is configured for \*\*Code::Blocks\*\* with the SDL library.



1. Prerequisites : Have Code::Blocks 25.03 (or compatible version) installed with MinGW.

2\. Opening : Double-click on the file `projetTowerDefend.cbp`.

3\. Compilation : Press F9\* (Build \& Run).

4\. Controls : 

&#x20;  `s` / `d` : Save (Binary / Sequential).

&#x20;  `c` / `v` : Load (Binary / Sequential).
